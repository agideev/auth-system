<h2 id="about">📖 About</h2>

**Auth System** is a full-stack authentication and user management application designed to provide a secure and modern experience for managing user accounts.

The application follows a client-server architecture and is organized as a monorepo containing two main applications:

* **Frontend** — Provides the user interface for registration, login, profile management and account actions.
* **Backend** — Provides the REST API responsible for authentication, user management, password updates and access control.

The project is designed with a clear separation of responsibilities between the frontend and backend, making the application easier to develop, test and maintain.
